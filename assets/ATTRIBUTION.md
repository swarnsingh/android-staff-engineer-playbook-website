# Visual Asset Attribution

This registry covers every SVG, PNG, JPEG, and WebP asset stored in this repository, including repository-authored visuals. Mermaid diagrams authored in the repository do not need individual entries, but their technical claims still require primary sources in the surrounding topic.

The repository's Creative Commons license does not replace or relicense third-party asset terms. Each reused asset retains its original license. Before adding an asset, verify that the specific image—not merely the page containing it—permits redistribution and modification.

## Registry

No external visual assets are currently stored in the repository.

When an asset is added, replace the sentence above with rows using this schema:

| Local asset | Used in | Creator | Original source | License | Changes | Retrieved |
|---|---|---|---|---|---|---|
| `assets/<tree>/<name>.<ext>` | `path/to/topic.md` | Name or organization | Canonical page URL | License name and URL | Unmodified, cropped, annotated, or adapted | YYYY-MM-DD |

## Reuse checklist

1. Confirm that the asset itself has an explicit reuse license or written permission.
2. Prefer primary documentation over a blog for technical truth. A blog image is acceptable only when its license permits reuse and the depicted behavior is independently verified.
3. Download the asset into `assets/<knowledge-tree>/`; never hotlink it.
4. Remove branding or trademarks only when the license permits modification. Do not imply endorsement.
5. Add meaningful alt text and a nearby explanation in the topic.
6. Record adaptations accurately and link the exact source page and license.
7. Review the asset whenever the surrounding version-sensitive content appears in the Currency Watchlist.
