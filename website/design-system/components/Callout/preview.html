A music app's play button freezes for two seconds, and the code behind it is one line: if (service.isPlaying()). The method looked local. The cost was not.

Staff note

Treat every cross-process call as a network call with better latency: give it a timeout budget, keep it off the main thread, and design the contract so a slow service degrades one feature, not the app.

Remember

A oneway call returns without waiting for the work, but the transaction still has to be accepted and delivered.
