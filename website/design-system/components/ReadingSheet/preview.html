The Binder

A method call that looks local can wait on another process's busy thread. Learn how Binder carries calls between processes and how to design contracts that cross them.

Start here

A music app's play button freezes for two seconds, and the code behind it is one line: if (service.isPlaying()). It reads like a getter. It is a request to another process, which has to wait for a free thread there.

Binder is how one Android process calls into another: your app into system services, and apps into each other. The cost of a call depends on the other side, not on how the call looks.
