# Checkpoint

A question the reader answers before opening it; the answer sits under its own **Answer** heading. Checkpoints live in the Q&A tab only.

## Rules

- The closed state shows the full question; the `+` disc on `accent` is the only affordance.
- The answer always starts with an `Answer` heading (`labelSmall` in `accent`) on its own line. The reader inserts it, so lesson content never writes its own.
- Answers use `bodyMedium` at 16px in `ink`, never handwriting.
- Three checkpoints per lesson section, as in the content rulebook.

## Tokens

`sheet-sunken`, `accent`, `on-accent`, `ink`, `focus`, `radius-md`, `radius-pill`, `radius-sm`.
