# Checkpoint

A question the reader answers before opening it; the answer sits under its own **Answer** heading. Checkpoints live in the Q&A tab only.

## Rules

- The closed state shows the full question; the `+` disc on `accent` is the only affordance. The question text sits in one wrapping span beside the disc (`summary` is a flex row of exactly two items), so a sentence never splits into columns; inline code inside it stays on one line.
- The answer always starts with an `Answer` heading (`labelSmall` in `accent`) on its own line. The reader inserts it, so lesson content never writes its own.
- Answers use `bodyMedium` at 16px in `ink`, never handwriting.
- As many checkpoints as the section needs to check understanding, often one to three. There is no fixed quota; never add a question just to fill a slot.

## Tokens

`sheet-sunken`, `accent`, `on-accent`, `ink`, `focus`, `radius-md`, `radius-pill`, `radius-sm`.
