## Candidates, not flagged on the pages

- **KO2:** the claim that every XCFramework host must upload a separate shared-framework dSYM may not hold for static frameworks, whose code is linked into the app binary. No Apple primary source was obtained, so the earlier notes were removed. The crash-bridge guidance in the same chapter is supported by Kotlin's FAQ and is **not** disputed.
- **KC8:** `kotlin.incremental.compilation.enabled` is not among the documented Kotlin incremental properties (`kotlin.incremental`, `kotlin.incremental.native`), and "`cacheKind=static` … only changed source sets are recompiled" conflates compiler caches with incremental compilation ([Improving compilation time](https://kotlinlang.org/docs/native-improving-compilation-time.html)). Owner verification needed.
- Minor: concurrency-and-memory says the Kotlin GC "adds the Swift object to its root set" (the ARC integration docs describe a strong reference released after GC); ci-cd uses the outdated `softprops/action-gh-release@v1`; `:shared:testDebugUnitTest` is the legacy Android-target task name.
